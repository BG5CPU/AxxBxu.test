It is workspace for controller synthesis for system $x^{+} = A(x)x + B(x)u$.  

`SimB/Model_stabilization_04.m` is for **Example 1** and **Example 2** in the paper.  

`SimB/Model_saturation_04.m` is for **Example 3** in the paper.  

`SimB/Data_stabilization_04.m` is for **Example 4** and **Example 5** in the paper.  

`SimB/Data_saturation_04.m` is for **Example 6** in the paper.  

`SimB/Data_cancellation_04.m` is for **Example 7** in the paper.  

> Note: The experimental input and process noise/disturbances are randomly generated, so the results may differ from run to run.

`SimC/Quadrotor08.m` is for **Section V-A** in the paper.  

`SimE` is for **Section V-B** in the paper.
