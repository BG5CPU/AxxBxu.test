%% ========================================================================
how to use control gain ===================================================
%% ========================================================================

Step 1:

obtain the following quaternion data.

/HR_leader/mavros/local_position/pose, field.pose.orientation.x
/HR_leader/mavros/local_position/pose, field.pose.orientation.y
/HR_leader/mavros/local_position/pose, field.pose.orientation.z
/HR_leader/mavros/local_position/pose, field.pose.orientation.w

convert a quaternion rotation to the corresponding Euler angles: Roll.x, Pitch.y, Yaw.z.
please note the order of the Euler angles (ZYX).



Step 2:

obtain the following velocity data.

/HR_leader/mavros/local_position/velocity_body field.twist.angular.x  -->  omega.x
/HR_leader/mavros/local_position/velocity_body field.twist.angular.y  -->  omega.y
/HR_leader/mavros/local_position/velocity_body field.twist.angular.z  -->  omega.z

obtain angular velocity: omega.x, omega.y, omega.z.



Step 3:

the state vector is 
state =
[ 
    Roll.x, Pitch.y, Yaw.z, omega.x, omega.y, omega.z 
]', 
which is 6*1.

the control gain is
vK =
[
   -0.0447    0.1157    0.0011   -0.0457   -0.0008   -0.0915
    0.0029   -0.1135    0.0183    0.0155    0.0279   -0.0278
    0.0347    0.1240   -0.0122    0.0601    0.0635    0.0588
],
which is 3*6.



Step 4:

calculate the control input, or the torque, for the actuator.

control.u = vK*state

/HR_leader/mavros/actuator_control field.controls0  <--  control.u.0
/HR_leader/mavros/actuator_control field.controls1  <--  control.u.1
/HR_leader/mavros/actuator_control field.controls2  <--  control.u.2
